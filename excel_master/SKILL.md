# 核心工作流 (SOP)
请严格按序执行以下步骤，不得跳过：

## 1. 数据探索 (EDA) - 了解你的数据
在解决问题前，必须全面掌握输入文件的结构与内容：
* **读取与概览**：使用 `read_file` 或 `bash_tool` 读取文件。如果是 Excel/表格文件，**必须首先打印所有 Sheet 的名称**，确保无遗漏。
* **深度检查**：切勿仅通过 `head(5)` 浅尝辄止。若发现表头混乱或格式异常，应增加预览行数，识别是否存在合并单元格或多层表头。
使用以下代码代替简单的`df.head()`命令，以看到复杂数据的全部列。
```python
import pandas as pd

# 设置显示所有列
pd.set_option('display.max_columns', None)

# 打印 head，此时所有列都会横向排列显示
print(df.head())
```
* **全貌掌握**：确保理解文件结构（多 Sheet 关系）、列定义、数据分布及潜在异常值。

## 2. 需求拆解 - 明确目标
基于 EDA 的结果，深入理解用户意图：
* **输出需求列表**：将用户需求转化为一个**清晰的编号列表 (Numbered List)** 并展示给用户。
* **严格执行**：后续操作必须逐项对齐该列表，确保不遗漏任何细节。
* 对于用户泛化的需求：比如分析出信息，多维度分析等，请调用`echarts` 技能生成图表以提供**丰富的可视化和报告**。

## 3. 能力研判 - 调用专用文档
根据拆解后的需求，显式判断是否需要读取以下专用能力文档（使用 `read_file` 读取）：
* **NLP 任务**（语义理解/生成/翻译等）：**必须**读取 `excel_master/abilities/batch_nlp.md`。
* **联网搜索**（每行数据的搜索/填充）：**必须**读取 `excel_master/abilities/batch_search_analysis.md`。
* **复杂 Excel 操作**（填模版/改公式/复杂格式）：**必须**读取 `excel_master/abilities/excel_api.md`。
* *警告：涉及上述场景若未读取文档，将被视为严重违规。*

## 4. 任务执行 - 策略选择
根据数据特征选择最合适的 Python 库：
* **Pandas**：适用于标准表头（第一行为列名）、数据分析、统计筛选、大数据量处理。
* **Openpyxl**：适用于非标准表头（复杂合并/样式怪异）、需要保留原格式、公式修改或在用户提供的模板上进行**原位微调 (Inplace Edit)**。
    * *注意*：处理复杂格式时，应在原表基础上修改并另存，而非重建。

## 5. 结果审查 (QA)
在交付前，必须对产出物进行自我审查：
* **数据完整性**：通过 Sample 抽样检查多行数据（不仅是头部），对比源文件与结果文件的行列数是否一致。
* **异常排查**：检查是否存在空值、错位或未满足用户需求的情况。如有错误，需针对性修正。

## 6. 结果交付
最后必须使用 `finish` 工具提交最终结果再结束：
* **格式遵循**：若用户指定格式（如 Markdown），严格遵照执行。
* **图表绘制**：除非用户强制要求 Python 绘图，否则**必须使用 `echarts` 技能**生成图表（注意中文编码）。
* **默认输出**：若无特殊要求，默认提供 `.xlsx` 统计文件及结论说明。
* **报告撰写**：若用户希望输出复杂详尽的报告，默认一定使用`.md`格式来撰写报告，严禁使用`.txt`格式
* **交付产物**：如果有需要呈现给用户的最终产物文件，先对产物进行简要介绍，但不要输出图片链接或产物名，然后需要调用`finish`工具并在 file_name 参数中填入所有的产物文件信息

# 最佳实践与技术规范

## Python 数据处理规范
1.  **库的选择**：
    * **预装库**: pandas, openpyxl, matplotlib, xlrd (请直接使用，无需安装)。
    * **快速运行**: 在进行数据探索时，可以适当使用`python -c`快速运行命令，进行数据处理时请务必创建代码文件并使用`python`命令运行。
    * **Excel**: 见上方流程 (Pandas vs Openpyxl)。注意 Openpyxl 索引从 1 开始，Pandas的DataFrame的to_excel方法没有encoding参数
    * **其他格式**：
        * PDF -> `PyPDF2`
        * Word -> `python-docx`
        * PPT -> `python-pptx`
        * OFD -> `odfpy`
2.  **修改 vs 提取**：
    * **修改/填表**：必须使用 `Openpyxl` 以防破坏原文件格式。
    * **内容提取**：尽量直接抄写/读取内容，**避免**使用复杂的正则表达式进行提取（除非数据量巨大且规律极强）。
3.  **代码风格**：保持简洁，去除冗余注释和无关 Print，指定 `dtype` 防止 Pandas 类型错误。

## 异常处理
1.  **报错分析**：仔细阅读 Traceback。
2.  **键值错误**：遇到 `KeyError`/`ValueError`，优先检查列名是否包含隐藏空格或特殊字符。
3.  **容错机制**：用户输入可能存在笔误，请结合文件内容进行合理推断或反问确认。
