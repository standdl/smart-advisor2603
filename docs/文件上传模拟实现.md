# 文件上传模拟实现文档

## 概述

本文档详细描述了智能参谋网站文件上传模拟功能的实现方案。该功能支持用户上传Excel（.xlsx/.xls/.xlsm）和PDF（.pdf）格式的财务报告与经营报告，模拟提取文件内容，并为后续AI诊断提供数据基础。

4. **进度显示**：上传过程中的进度条和状态提示
5. **历史记录**：模拟的历史报告列表，支持重新分析

#### 技术实现

**模板结构**：
- 模块选择卡片（响应式布局，移动端单列）

**脚本逻辑**：

- 响应式状态管理：`selectedModule`, `selectedFile`, `isUploading`, `uploadProgress`
- 计算属性：`progressText`（根据进度显示不同文本）
- 文件验证函数：`validateFile()`（检查类型和大小）
- 上传函数：`startUpload()`（调用模拟API，保存到localStorage，跳转结果页）

**样式设计**：

#### 关键代码片段

```javascript
// 文件验证逻辑
const validateFile = (file) => {
  const validTypes = [
    'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
    'application/vnd.ms-excel',
    'application/pdf'
  ];
  
  if (!validTypes.some(type => file.type === type)) {
    alert('不支持的文件格式，请上传Excel或PDF文件');
    return;
  }

  const maxSize = 50 * 1024 * 1024; // 50MB
  if (file.size > maxSize) {
    alert('文件大小超过50MB限制，请压缩或分割文件');
    return;
  }

  selectedFile.value = file;
};

// 上传处理逻辑
const startUpload = async () => {
  if (!selectedFile.value || !selectedModule.value) return;

  isUploading.value = true;
  uploadProgress.value = 10;

  try {
    // 模拟上传进度
    const progressInterval = setInterval(() => {
      if (uploadProgress.value < 90) {
        uploadProgress.value += 10;
      }
    }, 300);

    // 调用模拟API上传文件
    const result = await uploadFile(selectedFile.value, selectedModule.value);
    
    clearInterval(progressInterval);
    uploadProgress.value = 100;

    // 将提取的内容保存到localStorage，供结果页面使用
    localStorage.setItem('currentReport', JSON.stringify(result.data));
    
    // 延迟跳转，让用户看到进度完成
    setTimeout(() => {
      router.push(`/results/${result.data.reportId}`);
    }, 500);

  } catch (error) {
    console.error('上传失败:', error);
    alert(`上传失败: ${error.message}`);
    isUploading.value = false;
    uploadProgress.value = 0;
  }
};
```

## 模拟API接口设计

### upload.js 模块

#### 功能概述
提供模拟的文件上传和处理功能，模拟真实后端API的行为，为前端开发提供数据支持。

#### 接口函数

**1. uploadFile(file, moduleType)**
- **参数**：
  - `file`: File对象（来自用户上传）
  - `moduleType`: 诊断模块类型（'cost' | 'growth'）
- **返回值**：Promise\<object>，包含上传结果和提取的内容
- **功能**：
  - 模拟上传延迟（1500ms）
  - 调用`extractFileContent()`提取文件内容
  - 生成报告ID和时间戳
  - 调用`saveFileToServer()`模拟文件保存
  - 返回包含完整响应数据的对象

**2. getHistoryReports()**
- **返回值**：Promise\<Array>，模拟的历史报告列表
- **功能**：返回预定义的历史报告数据，用于前端显示

#### 文件内容提取逻辑

**PDF文件提取**：
- 模拟函数：`extractPDFContent(file)`
- 返回结构化的文本内容示例
- 实际环境中建议使用`pdf-parse`库

**Excel文件提取**：
- 模拟函数：`extractExcelContent(file)`
- 返回模拟的表格数据（利润表、资产负债表、现金流量表）
- 实际环境中建议使用`xlsx`库

#### 文件保存模拟
- 函数：`saveFileToServer(file, reportId)`
- 生成按时间戳命名的文件路径：`temp/uploads/upload_{reportId}_{timestamp}.{extension}`
- 在实际环境中，这里会将文件保存到服务器文件系统或云存储

## 文件处理逻辑

### 处理流程
1. **前端验证**：
   - 文件类型检查（仅允许.xlsx, .xls, .xlsm, .pdf）
   - 文件大小检查（≤50MB）
   - 文件名合法性检查

2. **模拟上传**：
   - 前端调用`uploadFile()`函数
   - 模拟网络延迟和进度更新
   - 返回包含提取内容的响应

3. **内容提取**：
   - **PDF文件**：提取文本内容，识别关键财务数据
   - **Excel文件**：解析表格数据，识别财务报表结构

4. **数据保存**：
   - 提取的内容保存到localStorage（供结果页面使用）
   - 模拟文件保存到`temp/uploads/`目录
   - 生成唯一的报告ID和时间戳

### 错误处理
1. **文件格式错误**：立即提示，不允许上传
2. **文件大小超标**：明确提示限制和解决方案
3. **网络中断**：模拟中断恢复机制
4. **解析失败**：提供标准模板下载建议
